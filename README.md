# rl-quadruped-locomotion
Deep Reinforcement Learning for quadruped robot locomotion with NVIDIA Isaac Lab and real-world hardware validation.

So the main goal is obtaining a stable locomotion system but using cheap and very accesible hardware. The model and the configurations are self made, from 0, and I will upload further information, as well as specifications of the physical robot model, as the training progresses. For now, the max speed of the robot is 12-14 cm /s on relatively harsh terrain.
